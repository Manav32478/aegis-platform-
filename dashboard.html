How it works

The failover loop, end to end
1. Router receives request
2. Health cache (10 s TTL) → pick healthiest cloud
3. Proxy request → Render / Vercel
4. Monitor polls every 5 min → Supabase
5. ML flags anomalies → risk_flags
6. Self-heal redeploys a cloud after 3 failures
