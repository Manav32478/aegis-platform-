Operating model

From probe to operator decision.

Monitoring, storage, analytics and request routing are separate parts of the system. Each one must be configured and verified before it can be relied on in a real deployment.

01

Probe

A monitor requests the common /health endpoint on each enabled origin and measures its response.

02

Record

When configured, health observations and incident transitions are written to Supabase for later review.

03

Operate

Operators compare current results, history and router diagnostics, then run controlled tests before making availability claims.
