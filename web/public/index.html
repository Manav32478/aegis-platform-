How it works

1 · Probe every 5 minutes

A monitor runs from three independent vantage points (Cloudflare edge, GitHub Actions, Oracle VM) and hits each cloud's /health endpoint, recording latency + status into Supabase.

2 · Score & decide

Every cloud gets a composite health score (uptime + latency + error rate). The router sends traffic to the highest scorer; the runner-up is held as a warm failover.

3 · Heal automatically

If a cloud fails N checks in a row, Aegis logs an incident, fires an alert (Slack/webhook) and triggers a redeploy of that cloud via GitHub Actions — no human needed.

☁️ Why 3 clouds?

  • No single point of failure — one provider outage is invisible to users.
  • Vendor independence — no lock-in to one free tier.
  • Genuinely free — each cloud's free tier covers the workload.
  • Measurable evidence — uptime %, latency, incidents, failover events.
