Add an application

Prepare configuration for two already-deployed origins. This tool runs in your browser; it does not deploy, save or change Aegis.

Use staging URLs only. Never enter passwords, API keys, or deploy hooks. Both origins must serve the same app and expose /health. This prototype is not a tenant-isolated deployment platform.

1. Worker TARGETS

Copy into the separate staging Worker's TARGETS variable. Do not change the live Worker.

2. Monitoring TARGETS
Copy into the isolated staging monitor and portal configuration. These use health URLs; the Worker's targets use base URLs.
Configuration is not applied automatically. See STAGING_RUNBOOK.md for verification and the remaining setup.
